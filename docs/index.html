Web Security Audit Skill

Agent Skills · Open Standard

White-box root-cause analysis + black-box behavior verification + a negative behavior test trio — for general-purpose web application security auditing.


View on GitHub →

Why it exists

Pure static (white-box) audit systematically misses behavior-side issues — malformed input returning 500 instead of 400, or an SPA fallback silently turning /db/blog.db into a 200 page that scanners mistake for a database leak. This skill pairs source analysis with live attacker-perspective verification, and encodes those lessons as a repeatable checklist.

White-box + black-box

Static root-cause pass (SQLi / XSS / auth / IDOR / CSRF / upload / traversal / SSRF / disclosure / deps) cross-validated against live behavior.

Negative behavior trio

Malformed inputs → assert 400/422 not 500; sensitive paths + content-type check → separate fallback artifacts from real leaks; unknown paths → 404 semantics.

Runnable probe script

scripts/probe.sh <url> runs the entire trio in one shot, with built-in pass/fail rules annotated.

Safety built-in

Authorized targets only. Fully non-destructive: no real injection, no brute-force, no data mutation.

为什么做这个

纯静态（白盒）审计会系统性漏掉行为侧问题——畸形输入返回 500 而非 400，或 SPA 兜底把 /db/blog.db 静默变成 200 页面、被扫描器误判为数据库泄露。本技能把源码分析与攻击者视角的线上验证结合，并把教训沉淀为可复用的核查清单。

白盒 + 黑盒结合

静态根因核查（SQLi / XSS / 认证 / 越权 / CSRF / 上传 / 路径遍历 / SSRF / 泄露 / 依赖），与线上行为交叉印证。

负面行为三件套

畸形输入 → 断言 400/422 而非 500；敏感路径 + content-type 校验 → 区分兜底假象与真实泄露；未知路径 → 404 语义。

可执行探测脚本

scripts/probe.sh <url> 一条命令跑完三件套，内置判定规则注释。

安全边界内置

仅限授权目标。全程非破坏性：无真实注入、无爆破、不触碰数据。
